# docs/NCM/ – Dados NCM e TIPI

- **data/** – Tabelas em JavaScript carregadas em runtime
  - `Tabela_NCM.js` → `window.NCM_TABELA_DATA`
  - `Tabela_TIPI.js` → `window.TIPI_TABELA_DATA`
- **fontes/** – JSON de origem (Tabela_NCM.json, Tabela_TIPI.json)

Usado pela Consulta de NCM em `src/modules/ncm/`.
